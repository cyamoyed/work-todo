# work-todo 设计约束 · 去 AI 味

> 基于 A 精密工作台 + C 日程轴，固化视觉与交互语言。
> 检索说明：本会话内 Google/DuckDuckGo 超时，知乎 403，百度跳转链失效；已对照 Linear 产品界面语言与「蓝紫渐变同质化」等问题，结合产品级 UI 工艺共识整理如下。

## 一、明确禁止（AI 模板特征）

| 禁止项 | 原因 |
|--------|------|
| 紫色/蓝紫渐变主色、霓虹发光 | AI 生成第一指纹 |
| 毛玻璃 / frosted glass 大面积铺底 | 同上，且影响可读性 |
| 卡片套卡片、列表项人人一张卡 | 伪高级、信息层级塌陷 |
| 居中大 Hero + 三列图标特性格 | SaaS 模板腔 |
| Emoji 当图标 | 不专业、跨平台不一致 |
| 胶囊渐变按钮、hover 放大 | 浮夸 |
| 装饰性几何粒子背景 | 与效率工具气质冲突 |
| 文案腔：赋能 / 无缝 / 一站式 / 智能体验 | AI 文风 |

## 二、必须遵守（世界级产品工艺）

1. **色板克制**：冷中性灰阶 + 最多 1 个强调色（靛青 `#4F46E5`）。语义色仅用于逾期红 / 进行中，面积极小。
2. **发丝线分行**：1px `#ECECEE` 分隔，列表是「一张台面」，不是一堆卡片。
3. **真实密度**：行高约 64px，允许信息密度接近 Linear / Superhuman，不刻意留巨大空白装优雅。
4. **字阶清晰**：界面 13–14px 基准，标题 15–16px，弱化 11–12px；标题用 600 字重，正文 400/500；数字 `tabular-nums`。
5. **图标线性**：16–18px 描边图标，与文字基线对齐；禁止填充插画风。
6. **交互克制**：hover 只改背景/边框色，不缩放不发光；焦点环清晰但低调。
7. **文案具体**：动词开头、短句、口语工作语感。「存入今天」「删除后可短暂撤销」，不说「智能管理您的任务」。
8. **状态可读**：三态（待办/进行中/已完成）有形状+文案+颜色三重编码，不只靠颜色。
9. **日程轴**：时间是主分组轴，逾期/今天/明天/本周稍后分段；时间列数字等宽右对齐。
10. **错误诚实**：文案与行为一致（可撤销就说可撤销）；危险操作焦点默认「取消」。

## 三、本原型的固定风格（A + C）

- **骨架**：左栏 228px 导航 + 主区列表；「日程」为一等视图（非附属日历）。
- **强调色**：靛青 `#4F46E5`；背景 `#FAFAFA` / 列表面 `#FFFFFF` / 侧栏 `#F4F4F5`。
- **列表**：发丝线行，圆形状态控件，备注一行摘要，右侧截止时间。
- **日程**：时间刻度左列 + 日期分段标题 + 右侧「今日节奏」统计条。
- **新建**：顶栏主按钮 + `N` 快捷键；快速记一笔 Enter 存入今天。

## 四、项目（Project）概念

- **定位**：把「任务台账」收拢成「工作项目」，但不引入看板/子任务/甘特，保持轻量。
- **模型**：`Project { id, name, color, createdAt, updatedAt }`；`Task.projectId` 可空（无项目）。
- **入口**：侧栏「项目」区；点击进入项目视图，顶栏显示项目进度（进行中 / 已完成 / 共 N）。
- **识别色**：仅 4 个低饱和色块（灰/墨/靛/褐），方块 8px，禁止彩虹色圆点标签。
- **行内呈现**：任务备注行前缀「小方块 + 项目名」，进入项目视图后隐藏（避免重复）。
- **快速记一笔**：若当前在项目视图，直接记入该项目。
- **进度**：选中项目时侧栏显示 3px 进度条；删除项目只解绑任务，不删任务。
- **数据**：导出/导入包含 `projects`；合并按 ID 去重。
